# CC · Campus Crash

🎓💥 CC · Campus Crash — 실제 대학 캠퍼스를 3D로 옮긴 웹 게임. 폭탄·미사일·핵폭탄·학점 총으로 숨은 전공책 더미를 찾고, 하늘에 떠다니는 F·D·C 학점 방울을 없애세요. 땅이 파이고 물기둥이 솟고 건물이 무너지는 물리 효과, 콤보와 업적까지! 설치 없이 휴대폰·태블릿·PC 브라우저에서 바로 플레이. 학교별 캠퍼스는 브랜치로 추가돼요 (현재: UNIST).

▶ **플레이:** https://novalab0401.github.io/Campus-Crash/

설치 없이 휴대폰·아이패드·컴퓨터 브라우저에서 바로 돌아가요. 휴대폰에서 공유 → "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 쓸 수 있어요.

## 조작
| | 컴퓨터 | 휴대폰·태블릿 |
|---|---|---|
| 둘러보기 | 드래그 | 드래그 |
| 이동 | WASD · Shift 달리기 | 왼쪽 방향 버튼 |
| 공격 | 클릭 · 스페이스 | 탭 |
| 무기 | 1 폭탄 · 2 미사일 · 3 핵폭탄 · 4 학점 총 | 아래 버튼 |
| 지도 보기 | V | 🗺️ |

## 학점 사냥
F +100 · D +60 · C +30 · B +10 · A −50 · A+ −100. 연속으로 지우면 콤보(최대 ×3), 폭발물로 바로 맞추면 직격 ×1.5. 업적 9개.
